# IMDB-Top-10-highest-rated-Movies
A basic Python script demonstrating data structuring and console output formatting. It iterates through a list of tuples containing the IMDB Top 10 movies and prints them using the enumerate() function and f-strings. This exercise highlights fundamental loops, tuple unpacking, and clean string formatting.

Before running the script check the python version (3.10+):
	python --version
	or python3 --version

Open the Terminal and enter:
	cd path/to/the/unziped/file
	python homework1_170326_IMDB.py

Expected output: 
	- 1. The Shawshank Redemption, Frank Darabont, 9.3
	- 2. The Godfather, Francis Ford Coppola, 9.2
	- 3. The Dark Knight, Christopher Nolan, 9.1
	- 4. The Godfather Part II, Francis Ford Coppola, 9.0
	- 5. 12 Angry Men, Sidney Lumet, 9.0
	- 6. The Lord of the Rings: The Return of the King, Peter Jackson, 9.0
	- 7. Schindler's List, Steven Spielberg, 9.0
	- 8. The Lord of the Rings: The Fellowship of the Ring, Peter Jackson, 8.9
	- 9. Pulp Fiction, Quentin Tarantino, 8.8
	- 10. The Good, the Bad and the Ugly, Sergio Leone, 8.8
